# Week 4 — Category C Assignment Problems (Java)

Solutions for the five assignment problems in the uploaded Category C assignment PDF.

1. Product of Array Except Self — prefix and suffix products; no division.
2. Maximum Subarray — Kadane's algorithm.
3. 3Sum — sorting, two pointers, and duplicate skipping.
4. Subarray Sum Equals K — prefix sums and a frequency map.
5. Find Minimum in Rotated Sorted Array — modified binary search.

Compile and run any file with `javac FileName.java` and `java ClassName`.
